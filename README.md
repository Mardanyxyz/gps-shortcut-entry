# The GPS Swears It Was a Shortcut

Entry for the make.fun bounty
[u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9)
("The GPS Swears It Was a Shortcut").

`main.ts` (pure Node, no dependencies) writes the GPS's one-line excuse to
`/output/entry.txt` and prints it to stdout:

> I sent you through the car wash with the windows down because the car needed a shower and I never promised to check the windows.

Run it with `node main.ts` (Node 22.18+).
